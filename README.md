# Hospital Emergency Room Analytics Dashboard

## 📌 Project Overview

This project analyzes **Hospital Emergency Room patient data** using Microsoft Excel and presents the analysis through an interactive dashboard.

The dashboard provides insights into patient visits, department referrals, gender distribution, admission status, waiting time, and patient satisfaction.

## 🎯 Project Objectives

- Analyze emergency room patient records
- Understand department-wise patient distribution
- Analyze patient admission status
- Track monthly patient visits
- Analyze average patient waiting time
- Understand patient satisfaction score distribution
- Build an interactive and professional Excel dashboard

## 📊 Dataset

- **Total Patient Records:** 9,216
- **Total Columns:** 12
- **Duplicate Patient IDs:** 0
- **Duplicate Rows:** 0

### Main Data Fields

- Patient ID
- Patient Admission Date
- Patient First Initial
- Patient Last Name
- Patient Gender
- Patient Age
- Patient Race
- Department Referral
- Patient Admission Flag
- Patient Satisfaction Score
- Patient Wait Time

## 🧹 Data Cleaning

The dataset was cleaned and prepared before analysis.

Key cleaning activities included:

- Checked duplicate records
- Checked duplicate Patient IDs
- Replaced `None` values in Department Referral with `No Referral`
- Reviewed missing values
- Prepared the cleaned data for Pivot Table analysis
